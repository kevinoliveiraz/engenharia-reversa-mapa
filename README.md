# Engenharia reversa — mapa Conexão Segura

Projeto de estudo em desenvolvimento: reconstrução manual do mapa do Conexão Segura para entender HTML, CSS e JavaScript, passo a passo.

## Conteúdo atual

- `index.html`: estrutura inicial do documento e referências aos recursos que serão implementados durante o estudo.
- `assets/favicon.png`: ícone do projeto.
- `anotações/`: resumos sobre as metas e os links do `<head>`.
- `.vscode/settings.json`: porta 5503 para o Live Server nesta pasta.

Esta versão registra o progresso do estudo. O corpo da página, os estilos locais e os módulos JavaScript ainda serão construídos.

## Abrir durante o estudo

Abra a pasta no VS Code e use o Live Server no `index.html`. A configuração atual usa `http://127.0.0.1:5503`.
